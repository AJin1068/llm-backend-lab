## 1. 요약

네 층을 따로 재요. 계산기가 맞는지, AI가 대화를 잘하는지, 근거 조문이 맞는지, 게이트웨이가 버티는지예요. 층을 섞으면 점수가 떨어졌을 때 어느 쪽이 문제인지 모르게 돼요.

## 2. 정답은 어디서 오나 (정답 사슬)

1. **계산기 검증**: 바깥 정답(국세청 책자 사례, 홈택스 모의계산)과 비교해요. 정답이 없는 곳은 성질 테스트("의료비가 늘었는데 세금이 늘면 안 된다")로 보완해요.
2. **AI 검증**: 가상 가구의 진짜 정보를 검증된 계산기에 넣어 만든 "기준 정답"과, AI가 대화로 알아낸 정보로 나온 답을 비교해요. 계산기는 같고 입력만 다르니, 이 점수는 AI가 대화를 잘했는지를 재요.

기준 정답은 100% 정답이 아니에요. 사례에 없는 애매한 규칙을 계산기가 잘못 해석하면 두 단계 모두 못 잡아요. 그래서 항상 "사례 n건·모의계산 n건으로 검증한 계산기로 만든 기준 정답"이라고 사슬을 밝혀요.

## 3. 층별 측정

| 층 | 정답은 어디서 | 재는 숫자 | 언제 돌리나 |
| --- | --- | --- | --- |
| 계산기 | 국세청 책자 사례, 홈택스 모의계산 기록 | 결정세액 일치 건수 / 전체 사례 수 | PR마다 CI에서 (회귀 테스트) |
| 계산기 (정답 없이) | 성질 규칙 | 가상 가구 1,000개 중 규칙 위반 건수 | PR마다 CI에서 |
| AI 대화 | 기준 정답 (검증된 계산기 + 진짜 가구 정보) | 배분안 일치율, 꼭 물어야 할 정보를 빠뜨린 비율, 잘못된 값을 넘긴 비율, 순서 규칙 위반 횟수, 대화당 비용 | 프롬프트·도구를 바꿀 때, 명령 하나로 |
| PDF 추출 | 가상 가구로 만든 PDF (정답 금액을 이미 앎) | 항목별 금액 일치율, 장당 비용, 처리 시간 | 추출 방법을 바꿀 때 |
| 근거 | 규칙표의 규칙 ID → 조문 연결 | 조문 적중률, 다른 연도 조문이 섞인 횟수 | 검색 방식을 바꿀 때 |
| 게이트웨이 | 평가 하네스 성공률 | 장애 주입 중 성공률(전/후), 응답 속도, 거절률 | 11/24 장애 주입, 11/28 k6 |

주의: "세액 일치율"은 계산기 점수라서 에이전트를 고쳐도 변하지 않아요. 에이전트 개선을 보여주는 숫자는 "배분안 일치율"이에요.

## 4. 평가 하네스가 돌아가는 방식

1. 시나리오 하나 = 가상 가구 정보 + 숨은 사실(예: "어머니는 연소득 없음"). v0는 10개로 시작해요.
2. 가상 사용자(AI)는 숨은 사실을 알지만, 에이전트가 물어볼 때만 대답해요.
3. 대화가 끝나면 에이전트의 최종 배분안을 기준 정답과 비교해 채점해요. 배분안 비교는 코드로 하고, 코드로 못 재는 부분(예: 설명이 판정과 맞나)만 GPT가 채점해요(키 이름 `OPENAI_API_KEY`, `.env.example`에 이름만). 채점 모델의 회사를 채점받는 모델(Claude)과 다르게 해서 "자기 답에 후한 점수"를 줄여요.
4. 틀린 대화는 도구 호출 로그로 원인을 분류해요: 정보 누락 / 잘못 알아들음 / 잘못된 값 / 순서 위반 / AI 호출 실패.
5. 결과는 날짜별 JSON으로 저장해서 전후를 비교해요.

## 5. 결과 공유와 CI

- **결과 파일을 PR에 같이 올려요.** 명령 하나로 점수를 계산하고, 결과 JSON을 PR에 넣고, 기준 수치와 자동 비교해 "떨어졌는지"까지 판정해요. 검증 세션은 숫자 해석과 코드 리뷰만 하면 돼요.
- **CI는 두 층이에요.** 모델을 안 부르는 것(사례 테스트, 성질 테스트)은 PR마다 자동으로, 모델을 부르는 하네스는 비용 때문에 검증 대상 PR에서만 직접 실행해요.
- **홀드아웃 모드**: 하네스가 레포 밖 경로의 시나리오를 읽어요. 맥북에서 사람이 돌려 숫자만 기록해요. 정답을 계산기가 만들기 때문에 매번 새 가구를 무작위로 만들어 채점할 수도 있어요.
- **답 외우기 검사**: 처리 코드·프롬프트에 시나리오 ID·사례 번호가 있으면 CI가 실패해요.
- **채점 규칙 검증**: 별도 세션이 규칙 문서만 보고 채점 코드의 테스트를 써요. 규칙에 맞음·틀림 예시를 붙여 애매한 정의("꼭 물어야 할 정보"가 무엇인가)를 줄여요.
- **PR 11(하네스 v0) 범위**: 결과 파일 형식, 기준 수치 비교, 레포 밖 시나리오 읽기, 1회 실행 비용 표시, 답 외우기 검사.
