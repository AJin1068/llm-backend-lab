# ADR-0006. Claude를 기본 모델로, GPT는 채점(judge)에만 쓴다

- 상태: 승인됨
- 날짜: 2026-11-11
- 결정자: 서아진

## 맥락

에이전트, PDF 추출, 가상 사용자, 채점에 모두 AI 모델이 필요하다. 한 모델로 전부 하면 비용이 커지고, 채점하는 모델과 채점받는 모델이 같으면 자기 답에 후한 점수를 줄 수 있다.

## 결정

- 메인 에이전트는 Claude Sonnet 5.5, PDF 추출과 가상 사용자는 Claude Haiku 5.5를 쓴다.
- 서비스 안 검증 에이전트도 Claude를 쓴다. 답을 만드는 쪽(메인 에이전트, 검증 에이전트)은 전부 Claude다.
- 코드로 채점할 수 없는 부분의 채점(judge)만 GPT가 맡는다. 채점하는 쪽만 다른 회사여야 자기 편향이 없다. 키 이름 `OPENAI_API_KEY`를 `.env.example`에 둔다.
- 모델 이름은 설정값으로 두고, 시나리오④(Haiku·Sonnet·Opus·Fable 비교)로 메인 모델 선택을 숫자로 확인한다.
- 폴백 모델 조합은 게이트웨이 단계(11/23~)에 정한다.

## 검토한 대안

- 전부 한 모델: 단순하지만 비용이 크고 채점이 편향될 수 있다.
- 채점도 Claude: 설정은 쉽지만 같은 회사 모델끼리 채점하는 문제가 남는다.
- 검증 GPT·채점 Claude: 메인 에이전트가 Claude라서 Claude가 대부분 Claude가 쓴 답을 채점하게 된다. 탈락.

## 결과

- 좋은 점: 하네스를 자주 돌려도 비용이 작다. 채점 편향을 줄인다. "왜 이 모델인가"를 비교 수치로 답할 수 있다.
- 나쁜 점: AI 회사 두 곳의 키·요금·호출 제한을 관리해야 한다.
