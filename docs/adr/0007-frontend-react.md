# ADR-0007. 화면은 React로 만든다

- 상태: 승인됨
- 날짜: 2026-11-11
- 결정자: 서아진

## 맥락

발표(11/27)에서 완성된 서비스로 보이려면 배분안 비교, 근거 조문, 스트리밍 채팅을 보여줄 화면이 필요하다.

## 결정

화면은 React로 만든다. v1에는 배분안 비교, 근거 조문 칩, 추출 확인 표, 스트리밍 채팅(PRD UI-01~04)을 넣고, 절세 카드와 중복공제 경고(UI-05~06)는 3주차에 넣는다.

## 검토한 대안

- 서버에서 그리는 간단한 화면(템플릿): 빠르지만 스트리밍·마우스 올림 같은 상호작용을 만들기 번거롭다.
- Streamlit 같은 데이터 앱 도구: 빠르지만 실제 서비스 화면처럼 보이기 어렵다.

## 결과

- 좋은 점: 가장 흔한 프런트엔드 기술이라 자료가 많고, 서비스다운 화면을 만들 수 있다.
- 나쁜 점: 백엔드가 중심인 포트폴리오에서 화면에 시간을 뺏길 수 있다. 그래서 기능을 6개로 제한한다.
