# ADR-0003. LLM은 계산하지 않는다

- 상태: 승인됨 (프로젝트 설계 원칙 1)
- 날짜: 2026-11-11
- 결정자: 서아진

## 맥락

세금 계산은 단계가 많고 한도·문턱이 얽혀 있다. LLM이 계산하면 그럴듯한 틀린 숫자를 낼 수 있고, 어디서 틀렸는지 추적이 안 된다.

## 결정

세액 계산·배분 비교·시뮬레이션은 계산 엔진(코드)이 하고, LLM은 정보 수집·도구 호출·설명만 한다. 공제율·한도 같은 숫자는 연도별 규칙표에 두고, 모델에 학습시키지 않는다. 답에 나온 금액이 계산 엔진 출력에 있는지 서비스 코드가 매번 검사한다.

## 검토한 대안

- LLM이 직접 계산: 구현은 쉽지만 틀린 숫자를 못 잡는다.
- 세법을 파인튜닝: 매년 다시 학습해야 하고 예전 연도 규칙이 섞여 나온다.

## 결과

- 좋은 점: 계산 결과를 국세청 사례로 테스트할 수 있다. 연도가 바뀌면 규칙표만 고친다. 이 결정의 효과는 시나리오① 실험(LLM 직접 계산 vs 도구 분리 일치율, 11/26)으로 숫자로 보인다.
- 나쁜 점: 규칙을 사람이 코드로 옮겨야 해서 초기 작업량이 크다.
