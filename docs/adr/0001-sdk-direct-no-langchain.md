# ADR-0001. LangChain 없이 SDK를 직접 호출한다

- 상태: 승인됨
- 날짜: 2026-11-11
- 결정자: 서아진

## 맥락

깊게 1의 핵심은 "AI가 도구에 잘못된 값을 넘기면 막고 다시 묻게 하기, 실패하면 몇 번 다시 할지, 최대 몇 번까지 부를지"를 설계하는 것이다. LangChain을 쓰면 이 부분이 라이브러리 안에서 돈다.

## 결정

AI 호출 루프, 도구 호출 검사, 평가 하네스는 AI 회사 SDK를 직접 호출해서 만든다. 작게 둔 부분(문서 자르기 같은 RAG 부품)은 라이브러리를 써도 된다.

## 검토한 대안

- LangChain/LangGraph로 전체 구성: 빨리 만들 수 있지만, 면접에서 "왜 이렇게 설계했나"의 답이 "라이브러리 기본값"이 된다.

## 결과

- 좋은 점: 실제로 모델에 무슨 요청이 갔는지 그대로 보인다. "잘못된 값 비율이 몇 %에서 몇 %로 줄었다"를 내 설계로 말할 수 있다. 라이브러리 버전업에 따른 유지보수 부담이 없다.
- 나쁜 점: 직접 만들 코드가 늘어난다. "LangChain 써봤나요?" 질문에 대비해, 여유가 있으면 하루짜리 LangChain 버전을 만들어 비교한다(미정).
